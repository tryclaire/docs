# Sources

Connect the sources your workspace uses to inspect collected activity. A token is optional.

## Choose a source

| Source | What it provides |
| --- | --- |
| [Telegram](telegram.md) | Stored chat messages and activity, with an optional join portal. |
| [X](x.md) | Connected profile, authored activity, follower snapshots, and collected mentions. |
| [Token](token.md) | Market and on-chain observations for a supported pons token. |

## Check collection status

Data can reflect an earlier collection rather than the moment you open a page. Check the connection and collection state on the relevant source page before using its figures.
