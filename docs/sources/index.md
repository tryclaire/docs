# Sources

Connect the sources your workspace uses to inspect collected activity. A token is optional.

## Choose a source

:::cards
::card[Telegram]{href=telegram.md icon=telegram}
Stored chat messages and activity, with an optional join portal.
::card[X]{href=x.md icon=x}
Connected profile, authored activity, follower snapshots, and collected mentions.
::card[Token]{href=token.md icon=coin}
Market and on-chain observations for pons on Robinhood Chain.
::card[Token actions]{href=token-actions/index.md icon=bolt}
Designate a wallet, launch a token, fund vesting, and publish allocation evidence.
:::

> [!NOTE]
> Ethereum (Stockereum) is coming soon and is not available yet.

## Organize what Claire knows

:::cards
::card[Knowledge and Assets]{href=context.md icon=book}
Organize context and control agent access.
:::

[Knowledge and Assets](context.md) describes the Knowledge page, the Claire uses and Agents read switches, People and private drafts. Connecting a source does not automatically permit external agent access.

## Check collection status

Data can reflect an earlier collection rather than the moment you open a page. Check the connection and collection state on the relevant source page before using its figures.
